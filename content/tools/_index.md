## 选择工具

- [JSON 格式化](/tools/json-formatter/)：整理 JSON、JSON5 和常见 Python 字典，查看语法高亮结果与解析错误。
- [cURL 转 Python requests](/tools/curl-to-requests/)：将常见 HTTP 请求命令转为 Python 代码，附 GET 和 JSON POST 示例。
- [Unix 时间戳转换](/tools/timestamp/)：转换秒、毫秒与日期时间，切换时区，批量处理并导出 CSV。

每个工具都有独立地址、使用说明和示例。命名转换、密码生成、图片预览和代理检测仍可从侧边栏打开；下方保留原有 JSON 快捷操作区。
