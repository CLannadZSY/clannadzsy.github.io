Unix 时间戳转换工具

使用方法

  1. 输入 Unix 时间戳，选择“自动识别”“秒”或“毫秒”，结果会随输入更新。
  2. 按需选择时区，例如 Asia/Shanghai、UTC，或输入 browser 使用浏览器本地时区。
  3. 查看 Unix 秒、毫秒、ISO 8601、所选时区的时间和相对时间，点击对应“复制”按钮获取结果。
  4. 也可以修改日期与时间，将该时区下的本地时间反向转换为时间戳；“填入当前”会使用当前时刻。

Unix 时间戳以 UTC 的 1970 年 1 月 1 日为起点；切换时区会改变同一时刻的显示方式。JavaScript 日期使用毫秒表示时间，相关背景见 MDN Date 文档。

示例：秒、毫秒与时区

选择时区 Asia/Shanghai，输入以下任一数值，都表示同一个时刻：

1704067200     （秒）
1704067200000  （毫秒）

两行仅用于对照；在单个转换的输入框中，每次粘贴一个数值，不包含括号内的单位说明。

预期结果：

输出项结果
Unix 秒1704067200
Unix 毫秒1704067200000
ISO 86012024-01-01T00:00:00.000Z
Asia/Shanghai2024-01-01 08:00:00 UTC+08:00
UTC2024-01-01 00:00:00 UTC+00:00

时间戳 0 对应 1970-01-01T00:00:00.000Z，在上海时区显示为同日 08:00:00。自动识别适合常见的秒、毫秒数值；历史日期或特殊范围应手动指定单位，以免按数值大小判断时产生歧义。

批量转换示例

切换到“批量转换”，每行输入一个时间戳，或不带时区后缀的日期时间。日期时间按上方所选时区解释，一次最多处理 500 个非空行。

1704067200
1704067200000
2024-01-01 08:00:00

选择 Asia/Shanghai 后，前两行会转换为 2024-01-01 08:00:00 UTC+08:00；第三行会转换为 1704067200 s / 1704067200000 ms。

点击“转换”查看每行的成功或失败状态。“复制结果”仅复制成功的转换，“导出 CSV”保留各行结果与错误信息，便于检查未能解析的输入。

时区与输入说明

使用 IANA 时区名称，例如 Asia/Shanghai 或 America/New_York，不要把日期本身的显示时间误认为 UTC。日期时间反向转换按秒处理；毫秒精度可直接通过时间戳输入保留。

无效时区、超出日期范围或不符合格式的输入会提示错误。夏令时切换造成不存在的本地时间时会报错；同一本地时间对应两个时刻时，会选择较早的一个并显示提示。相对时间基于当前时刻计算，随着时间变化会有所不同。
